RESUME CONFIGURATION:
---------------------
To enable direct resume downloads for visitors:
1. Place your compiled PDF resume in this `assets` directory.
2. Name it `Rohan_VS_Resume.pdf` (or update the filename in `script.js` under `RESUME_CONFIG.filename`).
3. The portfolio website will automatically detect and download it directly!
4. If no PDF is detected, the website gracefully informs visitors with an interactive modal and direct email link.
