## 🚀 How to Preview Locally

Because this website is built purely with standard HTML5, CSS3, and Vanilla JavaScript, it does not require any build steps or compilation!

### Option 1: Python Built-In Server (Recommended)
Open a terminal in the `my-portfolio` directory and run:

```bash
# Python 3
python -m http.server 3000
```
Then visit [`http://localhost:3000`](http://localhost:3000) in your browser.

### Option 2: Node.js (npx serve)
If you have Node.js installed:

```bash
npx -y serve .
```
Then open the displayed local URL (typically [`http://localhost:3000`](http://localhost:3000)).

### Option 3: Direct File Opening
Double-click `index.html` to open it directly in any modern browser (Chrome, Edge, Firefox, Safari).

## 🌐 How to Deploy

### Method 1: Deploy to GitHub Pages (Free)

1. **Initialize Git and commit**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Rohan VS developer portfolio"
   ```

2. **Create a GitHub repository**:
   - Go to [github.com/new](https://github.com/new).
   - Name it `my-portfolio` (or `vsrohan.github.io` for a personal root domain).
   - Keep it Public.

3. **Push your code to GitHub**:
   ```bash
   git remote add origin https://github.com/vsrohan/my-portfolio.git
   git branch -M main
   git push -u origin main
   ```

4. **Enable GitHub Pages**:
   - Navigate to your repository on GitHub.
   - Click **Settings** $\rightarrow$ **Pages** (under Code and automation).
   - Under **Build and deployment** $\rightarrow$ **Source**, select `Deploy from a branch`.
   - Under **Branch**, select `main` and folder `/ (root)`.
   - Click **Save**.
   - Your site will be live at `https://vsrohan.github.io/my-portfolio/` in 1–2 minutes!

---

### Method 2: Deploy to Vercel (Instant with Edge CDN & SSL)

1. Go to [vercel.com](https://vercel.com) and sign in with your GitHub account.
2. Click **Add New...** $\rightarrow$ **Project**, then import your `my-portfolio` GitHub repository.
3. Leave the Framework Preset as **Other** (since it's Vanilla HTML/CSS/JS).
4. Click **Deploy**.
5. Vercel will immediately deploy your portfolio to a global edge network with automatic SSL!
