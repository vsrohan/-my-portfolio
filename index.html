EyeDR AI — AI-Powered Diabetic Retinopathy Screening

EyeDR AI is an AI-powered web application that analyzes retinal fundus images to screen for signs of diabetic retinopathy. It uses deep learning to classify images into five severity categories and incorporates image-quality assessment, preprocessing, Grad-CAM visual explanations, confidence analysis, and multilingual report generation.

End-to-End System Pipeline

Startup Concept & Mission

EyeQ AI is my healthcare technology startup idea focused on developing a smartphone-assisted visual acuity screening solution. The proposed application aims to help users perform vision screening while investigating ways to improve the reliability of test conditions across different smartphones.

Planned Features & Investigation Areas

1. Visual Acuity Screening

Smartphone-based visual acuity screening with standardized digital optotypes.

2. Display Calibration

Physical display calibration to improve optotype sizing across variable screen sizes and pixel densities.

3. Viewing-Distance Monitoring

Investigation of viewing-distance monitoring to maintain consistent user-to-screen distance.

4. Ambient-Light Condition Checks

Verifying ambient-light conditions to prevent glare and test inconsistencies.

5. Test-Quality Checks

Real-time reliability validation during user vision tests.

6. Left-Eye and Right-Eye Testing

Independent monocular testing protocols for left and right eyes.

7. Screening Reports & Test History

Screening result reports and longitudinal test history tracking.

Flutter Dart SQLite Firebase ESP32 with suitable sensors
